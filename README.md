# Rodnik Desktop

Родник - личная новая вкладка с фоном, часами, погодой, группами ссылок и собственными значками.

## Скачать Родник

Этой страницей можно делиться с друзьями. Все доступные сборки собраны ниже.

| Браузер | Установка | Доступ |
| --- | --- | --- |
| Google Chrome | [Открыть Chrome Web Store](https://chromewebstore.google.com/detail/pnbkijkogidbccahihbllffpgipmdbee) | Закрытое тестирование по приглашению |
| Mozilla Firefox | [Открыть Mozilla Add-ons](https://addons.mozilla.org/ru/firefox/addon/rodnik-desktop/) | Версия 0.1.5 ожидает проверки Mozilla |
| Microsoft Edge | Пока недоступно | Сборка для магазина готовится |

## Доступ к Chrome

Передайте автору адрес своего аккаунта Google, чтобы он добавил вас в список тестеров. Затем откройте ссылку Chrome Web Store, войдя именно в этот аккаунт. Если магазин показывает «Этот продукт недоступен», проверьте выбранный аккаунт и уточните у автора, добавлены ли вы в список тестеров.

## Установка Firefox

Требуется Firefox Desktop 142 или новее.

Основной способ установки - [официальная страница Родника в Mozilla Add-ons](https://addons.mozilla.org/ru/firefox/addon/rodnik-desktop/). Первая магазинная версия 0.1.5 отправлена на проверку; до одобрения страница может быть недоступна обычным посетителям.

1. После публикации откройте страницу дополнения именно в Firefox.
2. Нажмите кнопку добавления в Firefox и подтвердите разрешения браузера.
3. Откройте новую вкладку.

Пакеты подписаны Mozilla. Ссылки и настройки хранятся локально в каждом браузере. Импорт и экспорт настроек доступны через меню рабочего стола. Личные настройки автора в пакеты не входят.

Обновления версии из Mozilla Add-ons доставляются через магазин.

## Резервная сборка

В [релизах GitHub](https://github.com/dan-zakirov/rodnik-desktop-releases/releases/latest) сохранён подписанный Mozilla XPI для ручной установки. Это запасной способ. Откройте в Firefox «Расширения и темы», затем меню с шестерёнкой и «Установить дополнение из файла». Выберите скачанный XPI и подтвердите разрешения. Не удаляйте установленное расширение перед обновлением, чтобы сохранить его данные.

Здесь размещаются только готовые пакеты и инструкция установки. Исходный репозиторий приложения и личные экспорты настроек не публикуются.
