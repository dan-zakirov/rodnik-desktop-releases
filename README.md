# Rodnik Desktop

Родник - личная новая вкладка с фоном, часами, погодой, группами ссылок и собственными значками.

## Скачать Родник

Этой страницей можно делиться с друзьями. Все доступные сборки собраны ниже.

| Браузер | Установка | Доступ |
| --- | --- | --- |
| Google Chrome | [Открыть Chrome Web Store](https://chromewebstore.google.com/detail/pnbkijkogidbccahihbllffpgipmdbee) | Общедоступная 0.1.8; обновление 0.1.9 ожидает проверки Google |
| Mozilla Firefox | [Открыть Mozilla Add-ons](https://addons.mozilla.org/ru/firefox/addon/rodnik-desktop/) | Общедоступная 0.1.9 |
| Microsoft Edge | Пока недоступно | Публикация отложена |

## Напоминания

В версии 0.1.9 системные уведомления встроены в расширение и включены по умолчанию. Пока браузер запущен, они появляются поверх других программ. Отдельная установка не нужна. В списке напоминаний можно выключить показ одним переключателем; события и расписание сохраняются. Видимость уведомлений зависит от настроек операционной системы и режима «Не беспокоить».

Напоминания можно показывать отдельной вкладкой рядом с группами ссылок или компактной сменяемой строкой. Поддерживаются дата, время, повторы, пауза, завершение и откладывание на 10 минут.

## Установка Firefox

Требуется Firefox Desktop 142 или новее.

Основной способ установки - [официальная страница Родника в Mozilla Add-ons](https://addons.mozilla.org/ru/firefox/addon/rodnik-desktop/). Версия 0.1.9 опубликована.

1. Откройте страницу дополнения именно в Firefox.
2. Нажмите кнопку добавления в Firefox и подтвердите разрешения браузера.
3. Откройте новую вкладку.

Пакеты подписаны Mozilla. Ссылки и настройки хранятся локально в каждом браузере. Импорт и экспорт настроек доступны через меню рабочего стола. Личные настройки автора в пакеты не входят.

Обновления версии из Mozilla Add-ons доставляются через магазин.

## Резервная сборка

В [релизах GitHub](https://github.com/dan-zakirov/rodnik-desktop-releases/releases/latest) сохранён подписанный Mozilla XPI для ручной установки. Это запасной способ. Откройте в Firefox «Расширения и темы», затем меню с шестерёнкой и «Установить дополнение из файла». Выберите скачанный XPI и подтвердите разрешения. Не удаляйте установленное расширение перед обновлением, чтобы сохранить его данные.

Здесь размещаются только готовые пакеты и инструкция установки. Исходный репозиторий приложения и личные экспорты настроек не публикуются.
