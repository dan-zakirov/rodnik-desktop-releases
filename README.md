# Rodnik Desktop

Готовые подписанные сборки Родника для Firefox. Личная новая вкладка с фоном, часами, погодой, группами ссылок и собственными значками.

## Установка Firefox

Требуется Firefox Desktop 142 или новее.

1. Откройте [последний релиз](https://github.com/dan-zakirov/rodnik-desktop-releases/releases/latest) и скачайте файл с расширением .xpi.
2. В Firefox откройте «Расширения и темы», затем меню с шестерёнкой и «Установить дополнение из файла».
3. Выберите скачанный XPI и подтвердите разрешения Firefox.
4. Откройте новую вкладку.

Пакеты подписаны Mozilla. Ссылки и настройки хранятся локально в каждом браузере. Импорт и экспорт настроек доступны через меню рабочего стола. Личные настройки автора в пакеты не входят.

Автоматические обновления Firefox пока не настроены. Для обновления скачайте новый подписанный XPI из релизов и установите его поверх предыдущей версии. Не удаляйте расширение перед обновлением, чтобы сохранить его данные.

Сборка Chrome пока доступна только приглашённым тестерам через [Chrome Web Store](https://chromewebstore.google.com/detail/pnbkijkogidbccahihbllffpgipmdbee). Публикация Edge ещё не завершена.

Здесь размещаются только готовые пакеты и инструкция установки. Исходный репозиторий приложения и личные экспорты настроек не публикуются.
